# Prototipos HTML (legacy — no implementables tal cual)

Estos 14 archivos HTML son mockups estáticos del viejo concepto "GrowUp Space" (pre-arquitectura V2): Tailwind vía CDN, Google Fonts, Material Symbols, layouts hardcodeados. **No forman parte del monorepo ni del build.** Se conservan únicamente como referencia visual histórica.

La implementación vigente vive en `apps/storefront` (dirección visual del prompt v0 `docs/prompts/v0-storefront.md`) y `apps/admin`. No copiar código de aquí; si se migra un patrón, reescribirlo con el stack real (Next.js, React 19, Tailwind 4, sin CDN).
